# CGH Browser Prototype

A mobile-first browser prototype for the CGH-inspired project.

## Current foundation

- Three.js first-person scene.
- Empty Train-void environment with atmospheric fog.
- Touch joystick movement and touch-drag look controls.
- Desktop WASD movement and mouse-drag look controls.
- Standard and push-style movement toggle.
- Lightweight rendering defaults for mobile.

## Not included yet

- Original monster models (waiting for user-provided model links/files and license checks).
- Monster AI, spawn-point data, random events, multiplayer server, and additional maps.
- Any claim that this is an authentic recreation of the original game's maps or assets.

## Run

Open `index.html` through a static web server or a host that serves ES modules. Three.js is loaded from jsDelivr, so the first load requires an internet connection.
